Tool · In use by my team · Built with Claude Code

Doxa: court and sanctions checks for title searches

5–6 h→2–3½ h

Time for an order with common names, before and after. Simple orders now take about 5 minutes.

Every title search order needs each party's name checked against US federal court records (PACER) and the US sanctions list (OFAC). By hand, that meant searching each site, saving every page of results and merging it all into one document.

  • Runs both checks for a whole list of names at once
  • Builds one print-ready PDF for the order, matched to the official layouts by measuring real printouts
  • Flags names that need a person to review, instead of guessing

I built it on my own initiative. I wrote the requirements, tested every output against real searches, and used Claude Code to write the code.
